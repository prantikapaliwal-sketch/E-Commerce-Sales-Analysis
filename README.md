# E-Commerce-Sales-Analysis
Advanced E-Commerce Sales Analysis using MySQL
## Project Overview
Designed and analyzed an E-Commerce database using MySQL to identify top-selling products, high-value customers, and monthly revenue trends.

## Database Tables
- Customers
- Products
- Orders
- Order_Details

## SQL Concepts Used
- INNER JOINs
- GROUP BY
- Aggregate Functions (SUM)
- ORDER BY
- CTEs (Common Table Expressions)

## Key Insights
- Identified top-selling products based on sales volume.
- Found high-value customers based on total spending.
- Analyzed monthly revenue trends.
- Generated business insights using SQL queries.

## Tools Used
- MySQL
